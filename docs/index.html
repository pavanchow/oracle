Query attack paths,

Oracle is a query language whose result is an attack path, not a set of rows.

Ask how a principal can reach a capability. Oracle returns the concrete chain of permissions and trust that gets them there, hop by hop, with the exact edge behind each step.

The core idea

Standard tools map assets.
Oracle maps attack paths.

An inventory tool tells you a role exists and a bucket is public. Oracle tells you that a user reaches full control in five hops, and names the exact permission or trust edge at each one.

What inventory gives you

Rows. A list of roles, a list of policies, a list of open ports. You still reconstruct, by hand, whether any of it chains into a real escalation.

What Oracle gives you

A walkable chain. user:alice to group:developers to role:build-runner to role:deployer to role:admin, each hop labeled with the edge that made it possible.

Oracle Query Language

OQL, by example

A hand-written lexer and recursive-descent parser. Path semantics are built into the language, not bolted onto a general-purpose graph query language.

PATHS FROM user("alice") TO action("*")
PATHS FROM user("alice") TO resource("prod-artifacts")
PATHS FROM user("alice") TO action("*") VIA can_assume, has_permission WITHIN 4 HOPS
ESCALATE FROM user("alice")
BLAST role("deployer")
How it's different

Prior art, and where Oracle diverges

BloodHound
Maps Active Directory attack paths in a Neo4j graph. Powerful, but AD-specific and driven by raw Cypher.
PMapper
Models AWS IAM as a graph and answers reachability, in Python.
Cartography / Prowler
Inventory cloud assets and flag misconfigurations. They map what exists, not what an attacker can chain.
Neo4j / Cypher
A general graph query language. Attack paths are expressible but not first class, you hand-write the traversal every time.
Oracle
The attack path is the primitive. Cloud-and-network native, not tied to one directory service. Every result is a walkable chain with the permission or trust edge at each hop.
Stack & status

Built in Rust, bounded by design

Language
Rust. A single static binary via cargo.
Parser
Hand-written OQL lexer and recursive-descent parser, no combinator dependency.
Path engine
Bounded, edge-aware depth-capped search on petgraph. Default 8 hops, 1000 results, reports truncation.
Working. Graph model, JSON loader, edge-aware bounded attack-path engine, the full OQL parser (PATHS, ESCALATE, BLAST), and a CLI.
Next. An AWS IAM importer, then an HTTP API and graph visualization UI, then an MCP server for agent access.
